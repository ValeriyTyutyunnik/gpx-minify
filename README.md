# gpx-minify

Простая утилита для очистки GPX-треков от мусора. Она полностью вырезает любые расширения (пульс, каденс, мощностью и т.п.), путевые точки и маршруты. 

Остается только чистый трек: координаты, высота и время. Блоки точек записываются компактно в одну строчку.

Нужен для сжатия треков для сервисов с ограничениями на размер трека. Например, o-gps-center.ru

## Запуск

Быстро без компиляции:
```bash
go run main.go -in "путь/к/файлу.gpx" -out "очищенный.gpx"
```

Через исполняемый файл:

```bash
# Сборка под текущую систему
go build -o gpx-minify main.go

# Запуск скомпилированного файла
./gpx-minify -in "in.gpx" -out "out.gpx"
```

## Параметры
* `-in` — исходный трек
* `-out` — файл для сохранения сжатого трека. По умолчанию `output.gpx`.
